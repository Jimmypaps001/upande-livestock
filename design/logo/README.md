# Livestock cow mark

The cow of the Livestock logo, still, for the mobile app. Generated by
`scripts/build_livestock_logo.py` (which also writes the animated desk tile and
splash loader in `upande_livestock/public/images/`); edit there and re-run.

| File                         | What                                                        |
|------------------------------|-------------------------------------------------------------|
| `livestock_cow_mark.svg`     | the white disc with the cow on her strip of grass (689 × 689) |
| `livestock_cow_mark_512.png` | the same, 512 px                                            |
| `livestock_cow_mark_1024.png`| the same, 1024 px (store icon / splash)                     |
| `livestock_cow.svg`          | the cow alone on her grass, cow in `currentColor`           |
| `livestock_cow_1024.png`     | the cow alone, in the mark's grey `#45433f`                 |

Colours: cow `#45433f` (the Upande arrow's grey), grass `#6a9a4c`.

On the web the mark moves: at rest it is the Upande disc and arrow; the arrow
shrinks away, the grass draws across, the cow walks in, and her tail swings a
little (pivot: the top of the tail). Timings are in the script (`CYCLE_MS`,
`ENTER`, `LOOP`).

PNGs are rendered with `rsvg-convert -w 1024 -h 1024 livestock_cow_mark.svg -o livestock_cow_mark_1024.png`.
